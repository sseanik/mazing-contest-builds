# Mazing Contest: test build

Thank you for testing! This is an early version of the game, so some things will be rough. That's exactly what we want to find.

## Install (Samsung phone or tablet)

1. On the phone or tablet, open the **Latest release** link on this page and tap the `.apk` file to download it (about 190 MB, so Wi-Fi is best).
2. When the download finishes, tap **Open**.
3. If Samsung says it can't install apps from this source, tap **Settings**, turn on **Allow from this source**, then go back and tap **Install**.
4. If Play Protect shows a warning, tap **More details** then **Install anyway**. That's normal for test apps that aren't in the Play Store yet.
5. Open **Mazing Contest**.

To update later, download the newer `.apk` from the latest release and install it over the top.

## What to try

Everything is unlocked in this version.

1. **Tutorial first.** Play it without help from anyone. If it doesn't teach you something, that's useful to know.
2. **Levels.** Play as many as you like, in any order.
3. **Practice** and **Random.** Try both.

## What to tell Sean

Write things down as they happen. Small things count. Notes like "I didn't know what this button did" are the most useful kind.

- Anything **confusing** or that you had to guess.
- Anything **annoying** or **slow**.
- Anything that looked **broken**: crashes, things stuck, wrong numbers, text cut off.
- What was **fun** and what made you want to stop.

Screenshots help a lot: press **Power + Volume down** together. A screen recording is even better: swipe down from the top and tap **Screen recorder**.

Send notes, screenshots and recordings to Sean by message, along with which device you were on (phone or tablet).
